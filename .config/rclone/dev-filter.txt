# Regras de exclusao para sincronizacao de desenvolvimento (rclone)
# IMPORTANTE: Nao usar regras '+' nem prefixo '**/' em pastas.
# Regras '+' ou '**/' desativam o pruning de diretorios do rclone e fazem ele
# varrer/criar milhares de subpastas de .venv, node_modules, .pio, .espidf e leis.
# Por padrao, o rclone ja inclui todos os arquivos e pastas ocultas (.git, .gemini, dist, scratch).

# Pastas pesadas de compilacao e caches de pacotes
- /leis/**
- .pio/**
- .espidf/**
- node_modules/**
- __pycache__/**
- *.pyc
- .venv/**

# Travas temporarias de git e arquivos temporarios de editor
- .git/index.lock
- .git/refs/heads/*.lock
- *.swp
- *~
- .DS_Store
